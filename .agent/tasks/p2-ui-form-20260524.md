## 必须执行的工作

1. 确认当前分支为 `worker/p2-ui-form`，当前 worktree 为 `.worktrees/p2-ui-form`。
2. 将 `create_main_window(config=None)` 返回的窗口改为真实表单窗口，至少包含：
   - generation config 保存路径；
   - prior manifest、checkpoint manifest、output root、generated id；
   - backend 选择；
   - anchor preset、structure anchor、random seed、sample steps、overlap；
   - 可选 condition packet、training index；
   - QC non-copy checkbox；
   - 6 类 label mapping 输入区。
3. 提供“保存配置”按钮，点击后将表单中的 generation 参数写为 JSON generation config。保存前必须校验数值范围和 label mapping 输入。
4. 提供“创建运行命令/任务”按钮或等价可测试入口；当必填路径缺失、generated id 为空、label mapping 非法或 torch backend 缺少 training index 时必须阻塞并显示错误。不要直接实现生产后台队列。
5. 保持 `launch_ui(config=None)` 可启动窗口，`ensure_pyside_available()` 行为不回退、不吞错。
6. 在 `tests/test_ui.py` 中增加最小可运行测试；如 PySide6 可用，使用 `QT_QPA_PLATFORM=offscreen` 创建窗口并验证：
   - 窗口不再只有 disabled button；
   - 表单控件存在；
   - 保存配置会写出合法 JSON；
   - 明显非法 label mapping 或缺失必填运行参数会被阻塞。
